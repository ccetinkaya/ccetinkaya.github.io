# Signalwerk

Signalwerk is a fictional project about using AI to spot patterns in security data and using context to decide which alerts deserve attention. This landing page illustrates the idea with examples such as unusual login times and access patterns.

## What’s on the page

- **Home** introduces the project and features a CSS-animated signal visualization.
- **AI** explains how models can flag unusual activity for review.
- **Cybersecurity** describes how permissions and known activity can help prioritize alerts.

The page uses a dark theme with cyan and violet accents. It adapts to mobile and desktop screens, supports keyboard navigation, and respects the device’s reduced-motion setting.

## Open the site

Open [index.html](index.html) in a web browser. The page works offline and requires no installation, server, or build step. The navigation links jump to sections on the same page.

## Edit the source

Edit [index.html](index.html) in a text editor to change the content or styling. All styles and animation are embedded in the HTML file. [The plain-text copy](index-quellcode.txt) contains the same source for easy copying.

The examples are illustrative. The page serves as a static demonstration and performs no monitoring, data collection, or AI analysis.
